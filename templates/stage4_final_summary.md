# 收尾模板：最终一页纸总结

> 使用时机：用户说"总结一下 / 收尾 / 出一页纸总结 / 最终总结"；或第三阶段交付完成时主动提供。
> 任何阶段都可触发，基于当前已有信息收敛，不强制走完三阶段。
> 排版：与第一阶段一致——加粗 + 短列表 + 自然段落，不用表格、不多级井号。

```markdown
# 最终一页纸总结

## 最终结论：近期主攻 / 战略探索 / 低成本验证 / 暂缓投入

一句话。如有变化，说明从什么变为什么（如"最初判战略探索，补全一段内部落地经历后上调为近期主攻"）。

**现在大概能不能做：** 高 / 中 / 低 / 目前还看不出来
**对下一步有没有价值：** 高 / 中 / 低 / 目前还看不出来

## 最有说服力的资产

- 资产一（为什么有力，一句话）
- 资产二（如有）

## 最大缺口 / 最大风险

- 缺口或风险一（为什么是它、影响什么）
- 缺口或风险二（如有）

## 必须先练

1. 第一优先（对应最大风险的化解动作）
2. 第二优先
3. 第三优先
4. 第四优先（如有）
5. 第五优先（如有）

## 待补清单（核心）

- 核心待补一
- 核心待补二

## 一句收尾

最优先的行动指令或一句话判断。
```

## 填写规则

| 要素 | 规则 |
|---|---|
| 最终结论 | 四档固定；有变化必须显式说明变化过程 |
| 资产 / 缺口 | 各一至两个，收敛后的最强者，不复述过程 |
| 必须先练 | 三至五项，从最终准备顺序收敛 |
| 待补清单 | 只列影响下一步的核心项；没有就省略 |
| 一句收尾 | 一个行动指令，不是感想 |
| 长度 | 600-900 字，一页内 |
