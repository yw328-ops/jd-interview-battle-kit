# 第一阶段模板：一页作战摘要

> 使用时机：用户提供一份或多份 JD（文字 / 截图 / 链接）后，**默认只输出本模板**。
> 长度控制：600-900 个汉字，最多一张核心表格。
> 硬规则：档位固定四档；不出现伪精确百分比；不出现内部代号（J1/P/Q 等）。

```markdown
# 一页作战摘要

## 结论：近期主攻 / 战略探索 / 低成本验证 / 暂缓投入

用一至两句话说清楚为什么。

| 现在大概能不能做 | 对下一步有没有价值 | 最大风险 |
|---|---|---|
| 高 / 中 / 低 / 目前还看不出来 | 高 / 中 / 低 / 目前还看不出来 | 一至两个关键问题 |

## 我为什么这样判断

- 岗位真正看重什么：
- 你目前最有利的地方：
- 现在最不确定或最危险的地方：

## 现在先做什么

只给一个最优先动作。（必要时可以加一个紧密相关的条件分支，但不能扩展成长待办清单。）

## 判断依据说明

- JD 明确写了什么：
- 哪些是根据岗位职责做出的合理判断：
- 哪些还需要通过公司研究或面试确认：
```

## 填写规则

| 字段 | 规则 |
|---|---|
| 结论 | 只用四档：近期主攻 / 战略探索 / 低成本验证 / 暂缓投入 |
| 现在大概能不能做 | 只用：高 / 中 / 低 / 目前还看不出来。没有用户经历时**不得**自行判断高中低，写"目前还看不出来"并说明缺什么 |
| 对下一步有没有价值 | 没有用户未来方向时，不得因公司有名/岗位热门就判"高"，写"目前还看不出来" |
| 最大风险 | 只突出一至两个最可能影响投递或面试结果的问题 |
| 现在先做什么 | 只给一个最优先动作，默认不列清单 |

## 多岗位版本

多份 JD 时不用本模板逐份套，改用横向比较表：

```markdown
# 多岗位作战摘要
| 岗位 | 现在大概能不能做 | 对下一步有没有价值 | 建议怎么投入 | 最大风险 | 现在先做什么 |
|---|---|---|---|---|---|
```

比较完成后明确告诉用户：哪个最值得主攻、哪个适合探索、哪个只适合低成本验证、哪个建议暂缓。
不要仅按岗位名称、公司知名度或薪资高低排序。
**转型用户提醒**：近期主攻是当前精力分配建议，不代表最终职业方向。
